# A.K. Gautam Traders — Website

Production-oriented Next.js App Router website for A.K. Gautam Traders, Jhansi.

## Stack
- Next.js 16+
- React 19
- TypeScript
- Tailwind CSS v4
- Lucide React
- Vercel-ready

## Run locally
```bash
npm install
npm run dev
```

## Production checks
```bash
npm run lint
npm run build
```

## Before deployment
Replace `example.com` in `app/robots.ts` and `app/sitemap.ts` with the final production domain. Add the final canonical metadata when the domain is confirmed.
