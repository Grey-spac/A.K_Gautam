# A.K. Gautam Traders — Production Website

Premium, responsive Next.js 16 App Router website for **A.K. Gautam Traders**, a Jhansi-based construction and building materials supplier.

## Stack
- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS v4
- Lucide React
- Vercel-ready

## Included
- Premium light mode by default + persistent dark mode
- Logo + site icon from the supplied brand assets
- Header navigation, call button, WhatsApp button and contact CTA
- Hero with 5-second clear image-first reveal, then animated SEO content
- Four hero images: A.K. Gautam Cabin, A.K. Gautam Group, A.K. Gautam and A.K. Gautam Office
- Hero image transition every 3 seconds after reveal
- Cursor-following winter-mist/fog effect on desktop
- Materials catalogue with supplied product imagery
- Material enquiry/order form that opens a WhatsApp message with all details
- Gallery using supplied business images
- Google Maps embed
- Google site verification meta tag
- LocalBusiness JSON-LD structured data
- Metadata, Open Graph, Twitter card, robots and sitemap
- Responsive mobile/tablet/desktop layout
- prefers-reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
```

## Deployment

Set `NEXT_PUBLIC_SITE_URL` to the real production domain before deploying to Vercel. This value is used for canonical URLs, structured data, Open Graph URLs, robots and sitemap.
